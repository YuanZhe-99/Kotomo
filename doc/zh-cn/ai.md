# 写作助手（设备端 AI）

Kotomo 的写作助手通过 ML Kit GenAI（AICore）用 Gemini Nano 校对和改写文字，遵循 `PLAN.md` §11 与行为约定中的 AI 规则。

## 规则

| 规则 | 实现方式 |
|---|---|
| 默认关闭 | `ai.enabled` 为 `false`（[settings-format.md](settings-format.md)）；关闭时 AI 按钮只显示提示，不创建任何 GenAI 客户端 |
| 只在请求时运行 | 在用户点按 AI 按钮并选择操作之前不运行任何东西；模型下载只能由“下载”按钮发起 |
| 不在按键路径上 | 键盘只负责交接文字；推理在前台页面 `AiActivity` 中运行，因为 GenAI 只服务前台应用 |
| 不在敏感输入框中运行 | 在敏感输入框（`Fields.sensitive`：密码、`IME_FLAG_NO_PERSONALIZED_LEARNING`）、直接输入的输入框（电子邮件、URL）和无痕模式中拒绝 |
| 预览、确认、撤销 | 先显示建议；只有点按“替换”才改动输入框，之后候选栏提供撤销，直到下一次按键 |
| 不离开设备 | Kotomo 不发送任何文字。模型由 AICore 通过系统下载；联网权限（由 ML Kit 合并进来，Kotomo 自身只用于用户发起的下载）从不携带输入的文字 |
| 不记录、不存储 | 文字与结果都不写入日志；交接只保存在内存中，界面未经“替换”就关闭时，选中的文字会从中清除（旋转等配置变化不会清除） |

## 交接

1. AI 按钮通过 `getExtractedText` 读取输入框：取选中的文字；未选中且整个输入框不超过 2,000 个字符时取整个输入框。更长的文字需要先选中。
2. 文字含假名时（或日文模式下不含拉丁字母时）语言为日语，否则为英语；含汉字且不含拉丁字母的文字会被拒绝，因为 GenAI 写作 API 只接受英语和日语。页面中可以切换语言。
3. `AiActivity` 在自己的任务中打开（`taskAffinity=""`），关闭后回到正在输入的应用。
4. 点按“替换”后，键盘在输入框恢复时检查：是同一个输入框（包名与字段 ID），且原范围内仍是原文。满足时替换该范围；否则把建议复制到剪贴板并提示。这次复制是一条普通的剪贴：剪贴板历史与快捷输入条像对待其他剪贴一样对待它（[clipboard.md](clipboard.md)），界面上的“复制”按钮也是如此。
5. 只有替换后的文字仍原样存在时，撤销才会恢复原文。

## 操作

| 操作 | API |
|---|---|
| 校对 | Proofreading，输入类型为键盘 |
| 换个说法、更正式、更亲切、更详细、更简短 | Rewriting：`REPHRASE`、`PROFESSIONAL`、`FRIENDLY`、`ELABORATE`、`SHORTEN` |

这些 API 接受少于 256 个 token。超过 400 个字符的文字在句末和换行处拆分，各部分分别处理后再拼接。单个句子超过该长度时以“太长”失败。

## 失败

| 失败 | 情形 |
|---|---|
| 不可用 | 没有 Gemini Nano、AICore 不兼容、需要系统更新、磁盘空间不足 |
| 后台 | AICore 拒绝了来自后台的请求 |
| 忙碌、配额 | AICore 正忙，或 Android 的单应用电池配额已用完 |
| 太长 | 请求超过 token 上限 |
| 被过滤 | AICore 拒绝处理该文字（从其消息判断；beta1 没有对应错误码） |
| 失败 | 其他情况 |

ML Kit GenAI 的 proofreading 与 rewriting 版本为 `1.0.0-beta1`，即其最新版本；后台与配额两种情形在该版本中没有错误码，从消息判断。
