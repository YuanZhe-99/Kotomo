### B4 日语模糊音的候选规则

以下是我拟的清单，待你确认增删。做法与中文模糊音一致：每条规则一个开关，默认全关；精确匹配和模糊匹配按常用程度一起排序；共享假名的规则不连带。

| 类别 | 规则 | 例子（打的 → 也能得到） |
|---|---|---|
| 长音 | 长音省略或多打：おう/お、うう/う、えい/え、おお/お、ー | `toukyo`、`tokyo` → 東京；`sense` → 先生；`koko` → 高校 |
| 促音 | 小っ省略或多打 | `kite` → 切手；`gakko` → 学校；`zashi` → 雑誌 |
| 拨音 | ん 的 n / nn，及其后接元音、や行时的混淆 | `konnichiha`、`konichiwa` → こんにちは；`kinen` ↔ `kinnen` |
| 清浊音 | か/が、た/だ、さ/ざ、は/ば 行互通（中文母语者最常见） | `watashi` ↔ `wadashi`；`arigato` ↔ `arikato` |
| 半浊音 | は/ぱ/ば | `ippai` ↔ `ipai`、`ibai` |
| 拗音 | きょ/きよ、しゅ/しゆ、りょ/りよ 等大小写混淆 | `kiyou` → 今日；`biyouin` ↔ `byouin`（病院/美容院） |
| 助词发音 | は/わ、を/お、へ/え 按发音打 | `watashiwa` → 私は；`gohano` → ご飯を；`gakkoue` → 学校へ |
| 四假名 | じ/ぢ、ず/づ | `tsuzuku`、`tuduku` → 続く；`hanaji` → 鼻血 |
| ら行 | r / l 互通；ら行与な行、だ行混淆 | `lamen` → ラーメン；`arigato` ↔ `aligato` |
| は行 | ふ 的 fu / hu；ひ/し 混淆 | `hito` ↔ `shito` |
| 外来语 | ヴ/ブ、ティ/チ、ファ/ハ 等片假名写法的出入 | `baiorin`、`vaiorin` → ヴァイオリン/バイオリン |
| 罗马字别写 | `cu` → つ（原 B3，用户确认）；其他非标准拼法待补 | `cuki` → 月 |

其中 shi/si、tsu/tu、chi/ti、ji/zi、fu/hu 这类标准的等价拼法现在已经支持，不算模糊音。
